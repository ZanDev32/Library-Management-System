# Phase 4: Librarian Dashboard & Polish - Plan 1 (Layout & Aesthetics)

## Goal
Update the `LibrarianDashboard` layout to a "Sidebar & Widget" design, implement the "Academic Clean" visual theme, and establish global CSS variables.

## Context
- **Theme:** "Academic Clean" (clean, white background, subtle shadows, professional typography).
- **Layout:** Sidebar showing metrics, main area showing the tabs and tables.

## Tasks

### 1. Define Global CSS Theme
**Description:** Establish the "Academic Clean" theme variables.
- **File:** `frontend/src/index.css` (or equivalent global CSS)
- **Action:**
  - Add CSS root variables for primary color (e.g. `#2c3e50` or `#800000`), background color (`#f8f9fa`), surface color (`#ffffff`), text colors, and subtle box shadows.
  - Apply clean font stacks (e.g., system-ui, Inter, Roboto).
  - Add micro-animations utility classes (`.smooth-transition { transition: all 0.3s ease; }`).

### 2. Update Librarian Dashboard Layout
**Description:** Refactor the dashboard to include a sidebar for metrics.
- **File:** `frontend/src/pages/LibrarianDashboard.jsx`
- **Action:**
  - Calculate `totalPending`, `totalActive`, and `totalOverdue` from the fetched `requests` array.
  - Render a side navigation/widget panel displaying these metrics.
  - Apply the new CSS classes for the clean academic theme.
  - Move the tab navigation to the main content area.

### 3. Polish Table Components
**Description:** Update existing tables to match the theme.
- **File:** `frontend/src/components/PendingRequestsTable.jsx` and `frontend/src/components/ActiveLoansTable.jsx`
- **Action:**
  - Apply clean borders, adequate padding, and subtle hover effects to table rows.

## Verification
- `<manual>` Open the app and verify the global styling is clean and professional.
- `<manual>` Log in as librarian, check that the dashboard shows a sidebar with accurate metric counts.
