# Phase 3: Borrowing System - Plan 5 (Frontend Librarian UI)

## Goal
Implement the React UI components and pages for librarians to manage borrowing requests and process returns.

## Context
- **Framework:** React.
- **Rules:**
  - Batch approve/reject support.
  - Reject requires a reason.
  - QR Code scanner integration for returns.

## Tasks

### 1. Create Librarian Borrow Dashboard
**Description:** A central dashboard to see pending requests, active loans, and waitlists.
- **File:** `frontend/src/pages/LibrarianDashboard.jsx`
- **Action:**
  - Create tabs for "Pending Requests", "Active Loans", "Waitlist".
  - Fetch respective data from backend.

### 2. Implement Batch Approve/Reject UI
**Description:** UI to select multiple pending requests and process them.
- **File:** `frontend/src/components/PendingRequestsTable.jsx`
- **Action:**
  - Render a table with checkboxes for each row.
  - Add "Approve Selected" and "Reject Selected" buttons.
  - If "Reject Selected" is clicked, open a modal prompting for the mandatory `reason`.
  - Call `POST /api/librarian/requests/process` with the payload.

### 3. Implement QR Scanner Component
**Description:** A component that accesses the device camera to scan QR codes for returns.
- **File:** `frontend/src/components/QRScanner.jsx`
- **Action:**
  - Install `html5-qrcode` or `react-qr-reader`.
  - Render the camera feed.
  - On successful scan, extract the `loan_id`.
  - Automatically call `POST /api/librarian/returns/scan` with the scanned ID.
  - Show a success toast ("Book returned successfully. X days late.").

### 4. Implement Pickup Marker
**Description:** Button in the Active Loans table to mark a book as picked up.
- **File:** `frontend/src/components/ActiveLoansTable.jsx`
- **Action:**
  - Add a "Mark Picked Up" button for loans with `status === APPROVED`.
  - Calls `POST /api/librarian/requests/{loan_id}/pickup`.

## Verification
- `<automated>` `npm run test -- librarian_ui_tests`
- `<manual>` Open librarian dashboard, test batch reject (ensure reason is required), test QR scanner component (mock scan).
