# Phase 3: Borrowing System - Plan 1 (Database Schema & Models)

## Goal
Implement the database models required to support the borrowing lifecycle (loans, waitlists, and extension requests) for the Library Management System.

## Context
- **Framework:** FastAPI (Backend) with PostgreSQL/SQLAlchemy ORM.
- **Dependencies:** Relies on `User` and `Book` models from Phases 1 & 2.
- **Rules:** 
  - `BorrowRequest` tracks pending, approved, returned, and rejected states.
  - Due date is 14 days from approval. Pickup deadline is 2 days from approval.
  - We need a `Waitlist` model for books with `available_copies == 0`.
  - We need an `ExtensionRequest` model for extending loans.

## Tasks

### 1. Create `BorrowRequest` Model
**Description:** Define the SQLAlchemy model for loan transactions.
- **File:** `backend/app/models/borrow.py` (or similar depending on actual structure)
- **Action:** Create `BorrowRequest` class.
- **Fields:**
  - `id`: UUID or Integer primary key
  - `user_id`: ForeignKey to User
  - `book_id`: ForeignKey to Book
  - `status`: Enum (`PENDING`, `APPROVED`, `REJECTED`, `RETURNED`, `CANCELLED`)
  - `request_date`: DateTime (default: now)
  - `approval_date`: DateTime (nullable)
  - `due_date`: DateTime (nullable)
  - `return_date`: DateTime (nullable)
  - `pickup_deadline`: DateTime (nullable)
  - `rejection_reason`: String (nullable)

### 2. Create `Waitlist` Model
**Description:** Define the model for students waiting for unavailable books.
- **File:** `backend/app/models/borrow.py`
- **Action:** Create `Waitlist` class.
- **Fields:**
  - `id`: Primary key
  - `user_id`: ForeignKey to User
  - `book_id`: ForeignKey to Book
  - `request_date`: DateTime (default: now)
  - `status`: Enum (`WAITING`, `FULFILLED`, `CANCELLED`)

### 3. Create `ExtensionRequest` Model
**Description:** Define the model for extending loan periods.
- **File:** `backend/app/models/borrow.py`
- **Action:** Create `ExtensionRequest` class.
- **Fields:**
  - `id`: Primary key
  - `borrow_request_id`: ForeignKey to BorrowRequest
  - `status`: Enum (`PENDING`, `APPROVED`, `REJECTED`)
  - `request_date`: DateTime (default: now)

### 4. Create Alembic Migration
**Description:** Generate and apply the database migration.
- **Command:** `alembic revision --autogenerate -m "Add borrowing models"` then `alembic upgrade head`. (Command execution will be handled in execution phase).
