# Phase 3: Borrowing System - Plan 4 (Frontend Student UI)

## Goal
Implement the React UI components and pages for students to interact with the borrowing system.

## Context
- **Framework:** React.
- **Rules:**
  - 2-step borrowing flow (click "Pinjam" -> modal/confirm -> submit).
  - Show "Masuk Antrian" if available_copies is 0.
  - Display student's active loans, pending requests, and their status.

## Tasks

### 1. Update Catalog UI (Borrow Button)
**Description:** Modify the book detail page or catalog cards to support borrowing.
- **File:** `frontend/src/components/BookCard.jsx` and `frontend/src/pages/BookDetail.jsx`
- **Action:**
  - Add a "Pinjam" button if `available_copies > 0`.
  - Add a "Masuk Antrian" button if `available_copies === 0`.
  - Clicking the button should open a Confirmation Modal (Step 2).

### 2. Create Borrow Confirmation Modal
**Description:** The second step of the 2-step borrow flow.
- **File:** `frontend/src/components/BorrowModal.jsx`
- **Action:**
  - Display the book title, estimated due date (14 days from approval), and a confirmation button.
  - On confirm, call `POST /api/borrow/request` (or `/waitlist`).
  - Show success toast and close modal.

### 3. Create "My Loans" Dashboard
**Description:** A page for students to see their borrowing history and active loans.
- **File:** `frontend/src/pages/MyLoans.jsx`
- **Action:**
  - Fetch user's `BorrowRequests` and `Waitlists`.
  - Display them in a table or list format.
  - Show status (`Menunggu`, `Disetujui`, `Ditolak`).
  - If `Disetujui`, show a button to generate/display the QR Code for return.

### 4. Implement QR Code Generator Component
**Description:** Component to render the QR code for a specific loan.
- **File:** `frontend/src/components/QRCodeDisplay.jsx`
- **Action:**
  - Install `qrcode.react`.
  - Render the QR code using the `loan.id` as the value.
  - This is what the student shows to the librarian when returning the book.

## Verification
- `<automated>` `npm run test -- borrow_ui_tests`
- `<manual>` Open student dashboard, verify 2-step borrow flow.
